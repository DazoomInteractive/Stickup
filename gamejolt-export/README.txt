GameJolt HTML5 Export
=====================

This folder is a standalone, build-free HTML5 export of the game.

Contents:
  index.html      - Entry point. Open this in a browser or upload the whole folder to GameJolt.
  index.js        - All game JavaScript (bundled, minified).
  favicon.svg     - Browser tab icon.
  icons.svg       - App icons.
  README.txt      - This file.

How to upload to GameJolt:
  1. Zip the contents of THIS folder (not the parent folder).
  2. On GameJolt, create a new game and choose HTML5 as the platform.
  3. Upload the zip file as your game build.
  4. Set the executable / main file to: index.html

Requirements:
  - A browser with JavaScript enabled.
  - Internet access (loads the Roboto font and ad scripts from CDNs).

No build steps are required. The game runs directly from these files.
